FORMA — коллекция готовых дизайнов

Откройте обновлённый HTML в браузере. В конструкторе выберите «Принт» или «Вышитый логотип», затем «Готовые дизайны».

Реализованы: поиск по всем словам запроса, тематические категории со счётчиками, фильтр стиля, сортировка по названию, избранное в localStorage (если разрешено браузером), страницы по 24 карточки, мгновенное нанесение после загрузки картинки, замена выбранного дизайна, удаление, масштаб и положение. При смене техники выбранный каталожный дизайн удаляется, чтобы принт не выдавался за вышивку. Дизайн и артикул включены в корзину и экспорт демозаказа. Исходные функции загрузки, примерочной и скачивания сохранены.

24 демонстрационных варианта: 12 сюжетов в двух техниках. Это не 24 производственно подготовленных файла. Реалистичной симуляции стежков и изготовления машинных программ вышивки нет.

Наполнение: в HTML найдите script с id="forma-catalog". В нём JSON-массив. Пример этого массива приложен отдельным JSON-файлом. HTML не загружает отдельный JSON автоматически — автономная работа без сервера сохранена намеренно. Для добавления дизайнов редактируйте встроенный массив. 500+ записей не требуют изменения логики интерфейса. Для большого каталога используйте небольшие thumbnail и отдельные image, предпочтительно на том же домене. Внешний сервер должен разрешать CORS; без этого скачивание canvas может быть заблокировано. Не вставляйте в image произвольные непроверенные SVG.

Поля: id (уникальный, латиница/цифры/дефисы), name, technique (print или logo), category, style, tags (массив), thumbnail, image, placements (center/left; первое значение — исходное положение), scale (40–200), published, demo. Новые изображения рекомендуется добавлять как PNG/WebP с прозрачным фоном. Размеры — условные единицы превью, не сантиметры и не производственные ограничения.

Проверка: выполнена синтаксическая проверка JavaScript через Node, если он доступен; результаты приведены в ответе. Автоматический браузерный прогон не выполнялся. Перед публикацией проверьте выбор/замену, поиск и фильтры, избранное, переключение техники, загрузку своего файла, корзину, JSON заказа, скачивание и мобильную версию. Нагрузочный браузерный тест на 500 реальных изображениях не выполнялся.
